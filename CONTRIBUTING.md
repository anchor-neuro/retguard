# Contributing

Bug reports and reproducibility issues are welcome via GitHub Issues. Please
include your operating system, Python version, onnxruntime version, and the
exact command that produced the problem.

The repository is not accepting feature pull requests while the accompanying
manuscript is under review. Fixes for demonstrable bugs are considered.

Questions about results reported in the paper should go to
ghoneim2012@gmail.com rather than the issue tracker.
